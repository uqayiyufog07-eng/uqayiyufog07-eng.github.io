把组卷网试卷导出成 PDF 和可编辑 Word：一个零依赖油猴脚本的实现

老钱2026-10-182026-10-18

一句话：在组卷网试卷详情页注入一个浮动面板，一键把试卷导出成 PDF 或 Word（可编辑文字＋局部图片 / 整题图片两种模式），全程本地运行，不上传任何数据。项目已开源：https://github.com/uqayiyufog07-eng/zujuan-export

背景

组卷网（zujuan.xkw.com）是中小学老师组卷、找题的常用站点。试卷页能在线看、也能打印，但真要拿来用的时候处处别扭：

  • 浏览器直接打印，会把导航栏、登录框、下载/收藏/分享按钮一起打进去，还得手调打印设置；
  • 下载 Word / PDF 要会员、要积分，答案解析还经常是图片，想整理进自己的题库得逐题截图；
  • 想「干净地」把一份试卷连答案带解析收进本地，官方途径基本没有好体验。

于是有了这个脚本：打开试卷详情页（形如 https://zujuan.xkw.com/11p3514663.html），右上角浮出一个小面板，勾选要不要答案解析，点按钮，拿到的就是一份干净的 PDF 或者一份文字可编辑的 Word。

它最初是一个 javascript: 书签脚本，后来转成油猴脚本并迭代到 v13，本文按最终版（13.2.0）介绍。

为什么是油猴脚本

选型上其实没怎么犹豫：

  • 纯本地运行：所有解析和导出逻辑都在浏览器里跑，不需要服务器，也不用把组卷网的登录 Cookie 交给任何第三方；
  • 复用登录态：答案解析图片要登录后才看得到，脚本跑在页面上下文里，天然带着你的登录态，不用单独处理鉴权；
  • 零外部依赖：html2canvas 1.4.1 整个内联进脚本（MIT 协议，保留版权头），不引 CDN，装一个脚本就能用，断网都能跑。

脚本头很诚实：

@grant none + @noframes：不申请任何特权 API，只在顶层框架跑，安过一次就用。

整体结构

脚本本体是一个 IIFE，大致四块：

模块 职责
门禁 + 就绪等待 只在试卷详情页运行，等正文渲染完成再启动
浮动面板 「包含答案解析」勾选、Word 模式切换、按钮与状态提示
PDF 导出 两条路：克隆弹窗打印 / 当前页含解析打印
Word 导出 手写 ZIP + WordprocessingML，混合 / 整题图片两种模式

门禁：只在试卷详情页运行

组卷网同域下有很多页面（首页、搜索页、列表页），脚本用一条正则把非试卷页全部挡掉，直接 return，不弹窗、不注入、不改 DOM：

试卷详情页的路径以「数字.html」结尾，一条正则足够精确。

就绪等待：最多轮询 2 秒

document-idle 时试卷正文可能还在异步渲染。脚本每 80ms 轮询一次试卷容器选择器，出现即启动；等满 2 秒还等不到就静默跳过，只在控制台留一行日志：

组卷网改版过多次，.exam-cnt、.paper-cnt 等新旧版式的容器选择器都列上，命中哪个用哪个——这也是它能在一个站点上活这么多版本的原因。

PDF 导出：两条路

不含解析走「克隆弹窗」：深拷贝试卷 DOM，剔掉 script、iframe、各种按钮和答案区，把页面所有 <link>/<style> 一起搬进新窗口，加一个 <base> 保证图片相对路径不塌，再塞一个醒目的「打印 / 另存为 PDF」按钮。用户点按钮走浏览器原生打印，选「另存为 PDF」即得一份干净文件。这条路还负责检测弹窗拦截，被拦了就明确提示。

含解析走「当前页打印」：答案解析是 <img>，弹窗克隆会丢跨域图片和懒加载状态，所以改成直接打印当前页。做法是给 source 到 body 的祖先链打上 xkw-local-print-path 标记类，配合一段 @media print 样式把祖先链之外的节点全部隐藏，同时藏掉站点自己的下载 / 收藏 / 分享区块；打印标题自动追加「-含答案解析」，afterprint 事件里清理现场，页面恢复原样。

导出前还有两道安检，宁可报错停工，也不导出一份漏题的残卷：

Word 导出：不依赖任何库

docx 本质是个 ZIP 包。脚本手写了一个 store 模式（不压缩） 的 ZIP 写入器：CRC32 查表、本地文件头、中央目录、EOCD，几十行搞定，不引 jszip、不引 docx.js：

包里只有五个部件：[Content_Types].xml、_rels/.rels、word/document.xml、word/_rels/document.xml.rels，加上 word/media/ 下的图片。document.xml 直接拼 WordprocessingML 字符串，<w:p> 段落、<w:r> 文本 run、<w:tbl> 表格全部手写。页面设置是标准 A4（11906×16838 twips），四边留白 900/850。

Word 提供两种模式，面板里可切换：

  • 整题图片（兼容）：html2canvas 按 2.5 倍缩放把每题截成 canvas，超过一页高度时智能切图——在候选切割线附近 ±130px 的范围内逐行统计深色像素，挑「文字最稀疏」的一刀切下去，避免把一行字拦腰截断；
  • 可编辑文字＋局部图片（默认）：把 DOM 转成 Word 原生段落和表格，只有公式、插图这类「图形叶子」才光栅化成图片。

混合模式：文字进 Word，公式变图片

这是整个脚本最核心的部分。判断走原生还是截图的，是一个 complex() 函数：

svg、canvas、math、MathJax、katex、ruby 等直接判复杂；文字很少却带背景图、或含绝对定位子元素的容器也算复杂——这类节点在 Word 里没法用原生元素还原，截图最稳。

文字 run 则完整保留计算样式：字体自动区分中西文（ascii 走 Times New Roman，eastAsia 识别宋体 / 黑体 / 楷体 / 仿宋 / 微软雅黑等）、字号、加粗、斜体、颜色、上下标，下划线连单线、波浪线（<w:u w:val="wave">）和点线（<w:em>）都对应到了 Word 原生属性。

表格转换保留了 colSpan / rowSpan / vMerge、边框粗细与颜色、垂直对齐，列宽按 twips（1 twip = 635 EMU）依页面比例换算；选项表（name="optionsTable"）按 5000 pct 宽度铺满页面。每题外面还包了一层 Word 内容控件（<w:sdt>），在 Word 里可以整题选中、整体移动。

组卷网特有的几个坑，脚本都专门处理了：

  1. <bk> 填空标签：转成下划线空位；<bk>42</bk> 这种预设了答案的，会按位数居中补足下划线，尽量贴近卷面效果；
  2. 完形 / 七选五选项识别：选项常常是一坨没有分隔的文本（1.A.xx B.xx）或一个 display:table 的容器。脚本先用正则把「题号 + 3~7 个 A 起连续选项」的结构解析出来，再生成真正的 Word 选项表格；相邻且列数相同的选项表还会自动合并，不会切成一堆小表格；
  3. 图片内联：跨域图片先 CORS fetch 成 dataURL 再塞进 docx，并且强制 decode() 校验，图片没解码完直接抛错停工——理由和 PDF 一样：不漏题比导得快重要。

docx 里的图片定位用 EMU 单位（914400 EMU = 1 英寸）。行内小图（比如行内公式）会用 <w:position> 做垂直居中微调，否则公式在 Word 里会「浮」在文字基线上方，版面发飘。

使用方法

  1. 安装 Tampermonkey（或暴力猴等油猴管理器）；
  2. 新建脚本，粘贴仓库里的 组卷网试卷导出.user.js 全文，保存；
  3. 打开任意组卷网试卷详情页，右上角即出现浮动面板；
  4. 勾选「包含答案和解析」时仅支持 PDF（Word 按钮会自动禁用）；Word 默认「可编辑文字＋局部图片」，兼容性优先可切「整题图片」。

完整源码在 GitHub：https://github.com/uqayiyufog07-eng/zujuan-export

后续：从油猴脚本到网页版

不是人人都会装油猴脚本。后来这套解析 / 导出逻辑被原样搬进了一个纯静态单页，用 Cloudflare Pages Functions 做服务端代理解决跨域与登录态，部署成了 https://zujuan.laoqian303.top ——无需油猴、无需扩展，粘贴试卷网址就能导出，文件还会归档到 R2。油猴脚本本身也在仓库里完整存档，作为最初的实现参考。脚本里预留的 window.__ZujuanAppSaveDocx、window.__ZujuanAppPrintPdf 两个钩子，就是给网页版复用的接口。
