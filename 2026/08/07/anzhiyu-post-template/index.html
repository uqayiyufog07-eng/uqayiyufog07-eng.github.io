四、使用注意事项

  1. 转义问题：正文中想显示 {% ... %} 原文时，用代码块包住（如本文 flink 示例），否则会被当标签解析报错。
  2. hide 标签：content 中不能含英文逗号，可用 &sbquo; 代替。
  3. top_img：只能写图片路径或 false，裸 true 会导致渲染报错 top_img.indexOf is not a function。
  4. 改完先清缓存：hexo clean && hexo g && hexo s。
  5. 更多标签：完整 25 个标签插件见官方示例页：https://hexo.anheyu.com/posts/d50a.html
